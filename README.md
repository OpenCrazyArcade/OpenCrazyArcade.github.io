# OpenCrazyArcade.github.io

Trang dự án OpenCrazyArcade, phát hành bằng GitHub Pages tại <https://opencrazyarcade.github.io>.

| Đường dẫn | Nội dung |
|---|---|
| `/` | Trang giới thiệu dự án |
| `/huong-dan/` | Hướng dẫn tải game và bắt đầu chơi |
| `/on-launcher/` | Tab "Trang dự án" của launcher: danh sách phiên bản AutoUpdate, cài hoặc hạ cấp qua launcher |
| `/assets/` | Kiểu dáng chung (`theme.css`, `landing.css`) và hình ảnh của trang |

Trang `on-launcher` đọc danh sách phiên bản từ Releases của [AutoUpdate](https://github.com/OpenCrazyArcade/AutoUpdate/releases);
trang `huong-dan` dẫn tới bộ cài game ở [Warehouse](https://github.com/OpenCrazyArcade/Warehouse/releases).
